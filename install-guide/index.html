Install Guide

How to install Lavender Linux

Download the ISO

Get the latest release from GitHub:

curl -O https://github.com/kosakovitch-2013/Lavender-Linux/releases/latest/download/lavender.iso

Flash to USB

Use dd to write the ISO:

sudo dd if=lavender.iso of=/dev/sdX bs=4M status=progress
sudo sync

Replace /dev/sdX with your actual USB device (check with lsblk).

Boot from USB

Restart your computer, enter BIOS boot menu (F12, F8, or Del), and select the USB drive.

Partition Your Disk

Inside Lavender, run:

cfdisk /dev/sda

Create a new MBR (dos) partition, write changes, and quit.

The Hard Disk/SSD might have different Interfaces like Nvme. /dev/nvme0 and /dev/nvme0p1 for partition.

Format and Install

mkfs.ext4 /dev/sda1
mount /dev/sda1 /mnt
cp -r /bin /boot /etc /sbin /usr /lib* /init /mnt/
mkdir -p /mnt/dev /mnt/proc /mnt/sys /mnt/tmp /mnt/root
touch /mnt/etc/linit/.installed

Install GRUB

grub-install --target=i386-pc --boot-directory=/mnt/boot --recheck /dev/sda

cat > /mnt/boot/grub/grub.cfg << 'EOF'
set timeout=5
set default=0
menuentry "Lavender Linux (Persistent)" {
    linux /boot/vmlinuz root=/dev/sda1 rw init=/init
}
EOF

umount /mnt

Reboot

poweroff

Remove the USB, start your computer, and boot into persistent Lavender 🌸
